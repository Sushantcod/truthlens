REST API Specification.

Integrate TruthLens credibility analysis directly into your browser extensions, news aggregation feeds, CMS plugins, or social media bots via programmatic REST endpoints.

API KEY AUTHENTICATION

Authentication Headers

Every request must supply an active developer token in either the X-API-Key or Authorization: Bearer <token> header. Obtain or regenerate your token in your User Profile. 

curl -X POST "{{ request.host_url }}api/predict" \
  -H "X-API-Key: YOUR_API_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"text": "SHOCKING BOMBSHELL: Secret cure discovered!"}'
POST /api/predict

Evaluates the input text against the soft-voting ensemble and knowledge-based rules. Returns classification probabilities, credibility score (0-100), rule flags, and influential feature attributions.

Request Payload (JSON)

{
  "text": "Delegates from over 190 nations reached a landmark emissions agreement.",
  "title": "Global Climate Accord Finalized",
  "domain": "un.org"
}

Response Payload (200 OK)

{
  "status": "success",
  "data": {
    "check_id": 42,
    "verdict": "REAL",
    "confidence": 92.4,
    "credibility_score": 90,
    "probabilities": {
      "REAL": 0.924,
      "FAKE": 0.076
    },
    "rule_flags": [
      {
        "rule": "VERIFIED_REPUTABLE_SOURCE",

      }

    "disclaimer": "TruthLens AI provides algorithmic credibility assistance to aid human critical reading..."
  }
}
GET /api/history

Retrieves paginated verification audit logs associated with your API credentials.

Query Parameters

  • page (integer, optional, default: 1): Page number
  • per_page (integer, optional, default: 10, max: 50): Number of records per page

Sample cURL Command

curl -X GET "{{ request.host_url }}api/history?page=1&per_page=5" \
  -H "X-API-Key: YOUR_API_KEY_HERE"
